# Coordinated repository review

1. Define the review scope.
2. Search for relevant paths and symbols.
3. Delegate only independent or specialized questions.
4. Read targeted sections. Do not read complete large files without a reason.
5. Trace callers, tests, and configuration when they affect the result.
6. Separate facts from assumptions.
7. Keep findings with direct evidence.
8. Merge duplicate findings.
9. Rank findings by impact.
10. Cite a file and line or symbol for each finding.
11. Give one direct action for each finding.
12. Stop when more context is unlikely to change the result.

Use a low-cost worker only for mechanical discovery or pattern copying. Keep architecture, security, concurrency, and debugging judgments in the correct specialist role.
