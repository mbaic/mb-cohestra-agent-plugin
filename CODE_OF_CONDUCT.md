# Code of conduct

This policy applies to issues, pull requests, discussions, and other spaces of this repository.

## Expected behavior

- Be respectful. Discuss the work, not the person.
- Give clear and kind feedback. Accept feedback in the same way.
- Assume good intent. Ask a question before you assume a mistake.
- Respect the privacy of other people.

## Unacceptable behavior

- Harassment, threats, or insults.
- Discriminatory language or conduct.
- Publishing private information about another person.
- Spam or deliberate disruption.

## Enforcement

The maintainer can edit, hide, or remove content that breaks this policy. The maintainer can block a person who repeats the behavior.

## Report a problem

Report a conduct problem to the maintainer, Milos Baic, through the contact options on [github.com/mbaic](https://github.com/mbaic). Do not post the report in a public issue. Report a security vulnerability through the process in [SECURITY.md](SECURITY.md).
